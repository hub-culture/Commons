# Contributing

Thank you for helping build the Global Commons.

## Ways to contribute

- **Add a commons** to `data/registry/` following `schema/commons.schema.json`. Run `python scripts/validate_registry.py` before opening a pull request. Write it with the people who keep that commons, in their terms.
- **Correct or extend the lineage map** in `scripts/build_lineage.py`. Every addition needs a source.
- **Improve the framework** in `framework/`. Open an issue first for large changes.
- **Build:** see `docs/roadmap.md` and `docs/cloud-mirror.md`.

## Ground rules

- Cite sources for facts and data.
- Never publish personal information about individuals in a community. Use counts or pseudonyms.
- Respect the consent and terms of communities and data holders.
- Label AI-generated contributions as such in the pull request.
